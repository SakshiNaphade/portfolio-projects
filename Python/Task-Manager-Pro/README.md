# Task Manager Pro

A command-line task management application built with Python. The application allows users to create, manage, update, and track tasks efficiently using JSON-based persistent storage.

## Features

* Add Tasks
* View Tasks
* Search Tasks
* Update Tasks
* Delete Tasks
* Mark Tasks as Completed
* Filter Tasks by Status and Priority
* Task Statistics Dashboard
* JSON Data Persistence

## Technologies Used

* Python
* JSON
* Git
* GitHub

## Project Structure

Task-Manager-Pro/

├── main.py

├── tasks.json

├── .gitignore

└── README.md

## How to Run

1. Clone the repository
2. Navigate to the project directory
3. Run:

python main.py

## Sample Task

{
"id": 1,
"title": "Learn Flask",
"priority": "High",
"status": "Pending",
"due_date": "2026-06-15"
}
