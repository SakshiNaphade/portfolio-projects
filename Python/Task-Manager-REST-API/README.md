# Task Manager REST API

A RESTful API built with Flask for managing tasks. The API supports full CRUD operations and stores data in JSON format.

## Features

* Create Tasks
* View All Tasks
* View Single Task
* Update Tasks
* Delete Tasks
* JSON Data Storage
* REST API Architecture

## API Endpoints

### Get All Tasks

GET /tasks

### Get Task By ID

GET /tasks/<id>

### Create Task

POST /tasks

### Update Task

PUT /tasks/<id>

### Delete Task

DELETE /tasks/<id>

## Technologies Used

* Python
* Flask
* JSON
* REST API
* Git
* GitHub

## Run Locally

Install dependencies:

pip install -r requirements.txt

Run application:

python app.py

Server runs on:

http://127.0.0.1:5000
